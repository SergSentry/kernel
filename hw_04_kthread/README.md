## HW_04_kthread

### Домашнее задание

Сформировать собственную коллекцию примеров использования API ядра Linux по примитивам синхронизации.

#### Цель:

Написать коллекцию примеров для работы с примитивами синхронизации в ядре Linux. 
Необходимо написать модули:

* ex_mutex.ko

* ex_spinlock.ko

* ex_semaphore.ko

* ex_rwlock.ko
