### Функционал

Модуль представляет простую модель IPC взаимодействия процессов. Поддерживает два режима работы UNICAST BROADCAST, режим задается в параметре *work_mode* при загрузке модуля.

* UNICAST   - work_mode = 0, режим, при котором запись данных выполняется по PID вызвавшего write процесса, и адресно по указанному PID при вызове ioctl. Режим установлен по умолчанию.

* BROADCAST - work_mode = 1, режим, при котором запись данных выполняется для всех работающих с модулем процессов.

### Принцип работы

После открытия функцией open модуля создается запись о клиенте(процессе) и выполняется запись в список активных процессов в /proc.
При поступлении запроса на запись формируется структура запроса, которая записывается в очередь запросов, и инициируется задача обработки для workqueue. Функция обработки извлекает из очереди запрос и в зависимости от режима работы записывает данные в очередь получения указанному процессу. Чтение данных для процесса выполняется по его PID, из очереди получения извлекаются данные и передаются получателю.
Закрытие модуля функцией close удаляет запись о клиенте(процессе) и удаляет его PID из списка активных процессов в /proc.

Сборка модуля выполняется вызовом в каталоге ./module команды:
```bash
make
```

Загрузка модуля выполняется вызовом в каталоге ./module команды:

Выгрузка модуля выполняется вызовом в каталоге ./module команды:

Очистка от файлов сборки и модуля выполняется вызовом в каталоге ./module команды:

```bash
make clean
```

Тест, проверка функций и параметров модуля выполняются вызовом в каталоге ./module команды:
```bash
make check
```

### Описание интерфейсов в /proc, /sys

#### /proc
Модуль регистрирует события открытия и закрытия его экземпляра. Идентификаторы PID активных процессов, работающих с экземпляром модуля, пишутся в файл /proc/exchange построчно.

#### /sys
Модуль имеет параметр запуска *work_mode*, доступный для чтения в файле /sys/module/exchange/parameters/work_mode.
Модуль видит статистику обработанных и потерянных запросов на запись. Статистика сохраняется в фвйле /sys/kernel/exchange/statistics и представляет собой записи в виде:
```txt
0
0
```
где первая строка - это общее количество успешных запросов на запись, вторая строка - количество отклоненных запросов на запись.
